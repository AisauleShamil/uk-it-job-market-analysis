# UK IT Job Market Analysis — Data Wrangling Project

## 📌 Project Overview
This project analyzes the UK IT job market to uncover trends in salary distributions, in-demand technical skills, and regional hiring patterns. The dataset undergoes full data wrangling, cleaning, and exploratory data analysis (EDA) using Python.

## 🛠️ Tech Stack & Skills
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Tools:** Jupyter Notebook, Git/GitHub
* **Data Techniques:** Data Wrangling, Missing Value Imputation, Data Normalization, Exploratory Data Analysis (EDA)

## 📁 Repository Structure
* `notebook.ipynb` — Complete Jupyter Notebook with code, output visualizations, and inline documentation.
* `data/` — Directory containing raw and cleaned datasets.
* `docs/` — Final presentation slides (PPT) and comprehensive project report (PDF).

## 📊 Key Insights & Results
* **Skill Demand:** Highlighted top required languages and tools across UK tech postings.
* **Salary Distribution:** Analyzed compensation variance based on role seniority and location.
* **Data Quality Improvements:** Handled missing values and standardized unstructured job title descriptions.
